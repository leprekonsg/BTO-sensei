1. Business Context

Business Objectives

Assist new homeowners and inspectors in conducting thorough Singapore HDB BTO handover checks. Automate logging, verify defect evidence computationally, and produce CONQUAS 2022-ready reports.

Users

New HDB homeowners conducting key collection checks, alongside professional defect inspectors and contractors.

Value Proposition

A fast, fully client-side inspection assistant combining Gemini-powered vision, live audio workflows, and HUD review mapped rigorously to CONQUAS rules.

Metrics for Success

Correct defect classification, precise app-side measurement checks mapping to pass/fail states, robust offline fallback capabilities, and processing speed on client devices.

6. Constraints & Execution

CONQUAS Verification Engine

Functional: Employs structured mapping decoupling measurements from AI text outputs. If the model measures a 3.5mm lippage, rigorous logic returns a failed grade per CONQUAS specs rather than trusting LLM sentiment.

Static Target Architecture

Non-functional: 100% Client-side. No API routing or backend servers needed beyond standard CDN distribution. Employs offline-capable fallbacks with ephemeral state ensuring zero persistent payloads.
